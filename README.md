# ⚔️ Война и Мир — мини-KaM для GitHub Pages

Браузерная стратегия «в духе» Knights and Merchants: The Shattered Kingdom
(в России издавалась как «Война и Мир»). Написана с нуля на чистом JS + Canvas,
без внешних картинок и библиотек — вся графика рисуется кодом.

## Что внутри (v0.1)

- 🗺️ Процедурная карта: лес, скалы, вода, жилы золота/железа
- 🛣️ Дороги + сервы-носильщики (по дорогам быстрее, как в оригинале)
- 🏗️ Стройка: строители + подвоз дерева/камня
- 🎓 Школа (сервы/строители/рекруты), 🍺 Таверна и **голод** — голодный бросает работу, потом умирает
- ⛓️ Цепочки: дерево→доски, пшеница→хлеб, пшеница→свиньи→колбаса, железо→оружие/броня
- ⚜️ Казармы: 5 типов солдат (ополченец, копейщик, лучник, мечник, рыцарь)
- ⚔️ Отряды с выделением рамкой, приказы ПКМ, **потеря контроля в бою** как в KaM
- 🗼 Башни с гарнизоном-лучником, 🍖 кормление солдат в поле
- 👹 ИИ: база врага + волны атак, таверна и пополнение армии
- 🏆 Победа/поражение, 3 миссии, скорость x1–x3, миникарта

## Управление

ЛКМ — выбрать/поставить · ПКМ — приказ · R — дорога · F — накормить ·
1–0 — постройки · WASD/стрелки — камера · колесо — зум · пробел — к базе

## Запуск локально

Просто открой `index.html` в браузере (сервер не нужен).
Или: `python -m http.server` → http://localhost:8000

## Публикация на GitHub Pages

```powershell
git add .
git commit -m "Mini-KaM v0.1: playable browser strategy"
git remote add origin https://github.com/superpirov/kam.git
git push -u origin master
```

Затем: **Settings → Pages → Deploy from a branch → master → /(root) → Save**.
Игра появится на `https://superpirov.github.io/kam/`.

## Планы
