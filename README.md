# ⚔️ KaM: Война и Мир — Браузерная стратегия

Браузерная стратегия в духе Knights and Merchants: The Shattered Kingdom. Написана на чистом JavaScript + Canvas с современной графикой.

## Что внутри

- 🗺️ Процедурная генерация карты (лес, вода, горы, золото, железо)
- 🏗️ Строительство: дома, казармы, башни, фермы, шахты
- 👷 Рабочие собирают ресурсы (дерево, камень, золото, железо)
- ⚔️ Юниты: рабочие, солдаты, лучники, рыцари
- 🤖 ИИ противника с волнами атак
- 🎨 Современная графика: градиенты, частицы, плавные анимации
- 🗺️ Миникарта
- 🏆 Победа/поражение

## Управление

| Действие | Клавиша |
|----------|---------|
| Выбрать юнита | ЛКМ |
| Приказ (движение) | ПКМ |
| Камера | WASD / стрелки |
| Зум | Колесо мыши |
| Построить дом | 1 |
| Построить казарму | 2 |
| Построить башню | 3 |
| Построить ферму | 4 |
| Построить шахту | 5 |
| К базе | Пробел |
| Скорость игры | +/- |
| Пауза | P |

## Запуск локально

Просто открой `index.html` в браузере. Или:

```bash
python -m http.server 8000
```

Затем открой http://localhost:8000

## Публикация на GitHub Pages

1. Запушь изменения в репозиторий
2. Settings → Pages → Deploy from a branch → main → /(root) → Save
3. Игра появится на `https://superpirov.github.io/kam/`

## Технологии

- HTML5 Canvas
- JavaScript (ES6+)
- CSS3 (backdrop-filter, анимации)
- Web Audio API
